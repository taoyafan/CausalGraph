## 2. 架构方案（CausalGraph 架构）

### 2.1 基础模型：纯 Node + Edge 与数据源解耦

- **极简图模型**：放弃复杂插件系统，将数据、逻辑、算子、突发事件全部抽象为 **Node（节点）**，连线 **Edge（有向边）** 仅代表数据与事件的传导方向。
- **数据源独立**：数据源仅生成属于自己的独占数据节点（带 `Source_ID`），不直接改写图上现有节点。不同数据源对同一指标的碰撞，由后置的**算子节点（Function Node）**进行加权与融合。

### 2.2 双重约束：固定算子库 + 固定概率分布库

- **算子库约束**：AI Parsing 不得自由编写任意脚本，只能从预设的标准算子库（如弹性算子、成本加成算子等）中挑选并填充参数。
- **概率分布库约束**：固定为 4 种标准分布：

  | 分布 | 名称 | 参数语义 |
  |------|------|----------|
  | `Uniform` | 均匀分布 | 上下界 |
  | `Triangular` | 三角分布 | 最悲观 / 最可能 / 最乐观 |
  | `Normal` | 正态分布 | 均值 / 标准差 |
  | `Point / Bernoulli` | 单点 / 伯努利分布 | 确定值 / 二元概率 |

### 2.3 概率与置信度融合机制

**节点二元属性：**

- **数据节点**：承载概率分布（数值波动）与数据源置信度 $C_{data}$。
- **算子节点**：纯数学算子不打折（$C_{op} = 1.0$）；主观推断/假设算子按逻辑把握度打折传递（$C_{op} < 1.0$）。

**混合无信息分布（Mixture Model）**：置信度 $C$ 作为展宽因子。置信度越低，原始分布越向“行业常识/宽分布”退化，防止低质信息或小道消息污染全图。

**缺项处理**：缺失数据源的“推断节点”自动填入高熵宽分布并赋低置信度（如 $0.2$），引发下游不确定性膨胀。

### 2.4 层级解包与响应式风控引擎

- **Baseline + Delta 层级结构**：采用 `新总值 = 基线 + Delta` 算子叠加微观事件，解决宏微观层级打架问题。
- **下游脏标记与变化阻断**：更新发生时沿着 Downstream 拓扑路径进行 Dirty Marking；若算子计算输出无明显变化，触发 **Short-circuiting（变化阻断）** 终止后续计算。
- **自动化风控链路**：下游概率方差剧烈膨胀或数值离群时 → 阻断传导 → AI 自审 → 上报管理员待办 → 生成定向 AI 补全 Task。

### 2.5 CLI 交互层（Text-based DSL Engine）

- **字符树 + 管道符**：输出以 `Focus_Node_ID` 为中心的 `[UPSTREAM] → [FOCUS] → [DOWNSTREAM]` 局部子图。
- **语义显式化**：用 `()` 标记数据节点，用 `[]` 标记算子节点，末尾直接追加 `ALERT` 标记（如 `ALERT: High Variance`），方便 AI Agent 直观抓取风险。

## 3. Use Cases

> 用真实产业链场景验证“数据接入 → 算子推演 → 概率传导 → CLI 呈现”的完整闭环。

### 3.1 新宙邦 2026 下半年业绩预测

**目标**：预测新宙邦（Capchem）2026H2 归母净利润的概率区间，并可回溯每个假设的数据源与置信度。

**业务逻辑链（简化）：**

```text
(电解液出货量) ──┐
                 ├─[量价加成算子]─→ (电解液收入) ──┐
(电解液均价)   ──┘                                 ├─[毛利算子]─→ (电解液毛利) ──┐
(单吨成本)     ──────────────────────────────────┘                            │
                                                                              ├─[汇总算子]─→ (营业利润) ─[净利率算子]─→ (2026H2 归母净利润)
(氟化工/电容化学品收入) ─[毛利算子]─→ (其它业务毛利) ───────────────────────────┘
```

**输入数据节点（示例，需替换为真实研报数据）：**

| 节点 | 分布类型 | 参数 | 数据源 | 置信度 $C$ |
|------|----------|------|--------|-----------|
| `(电解液出货量_26H2)` | Triangular | 悲观/可能/乐观（万吨） | 券商 A 研报 | 0.7 |
| `(电解液均价_26H2)` | Normal | 均值/标准差（元/吨） | 券商 B + 现货报价 | 0.6 |
| `(单吨成本_26H2)` | Triangular | 悲观/可能/乐观（元/吨） | 财报成本拆分 | 0.8 |
| `(其它业务收入_26H2)` | Normal | 均值/标准差（亿元） | 公司指引 | 0.5 |

**算子节点（示例）：**

| 算子 | 类型 | $C_{op}$ | 说明 |
|------|------|----------|------|
| `[量价加成算子]` | 数学算子 | 1.0 | 收入 = 出货量 × 均价 |
| `[毛利算子]` | 数学算子 | 1.0 | 毛利 = 收入 − 成本 |
| `[净利率算子]` | 推断算子 | 0.7 | 由历史净利率区间外推 |

**预期 CLI 输出（示意）：**

```text
cgraph focus 归母净利润_26H2 --depth 2

[UPSTREAM]
  (电解液收入_26H2)   ~ Normal(μ=..., σ=...)   C=0.6
  (电解液毛利_26H2)   ~ Triangular(...)         C=0.6
  (其它业务毛利_26H2) ~ Normal(...)             C=0.5
        │
        ▼
[FOCUS] (归母净利润_26H2) ~ Triangular(P10=.., P50=.., P90=..)  C=0.55
        │
        ▼
[DOWNSTREAM]
  (对应 EPS_26H2)     ~ ...   ALERT: High Variance (净利率外推置信度偏低)
```
