# 产业链结构层：锂电首条链（环节级）

> 对应 README 需求 6/7 的第一个落地，已落盘（check 0 error 0 warn）。本文只记结论。

## 1. 骨架与命名

碳酸锂 → 六氟磷酸锂 → 电解液（溶剂 / 添加剂）→ 电池（宁德时代）

- 环节节点用 `ind.*` 命名空间；公司节点用公司前缀（`capchem.*`、`catl.*`）。
- 跨公司与环节的连接靠算子 `inputs` 引用节点 id（边仍是纯拓扑，关系数据由独立节点承载）。

## 2. 节点范围

- **环节数据**：环节价格（多来源各建节点）、六氟供需比与缺口、单吨电解液六氟用量。
- **公司挂载**：只保留进入利润计算的量与系数（见 §7）；不参与利润/视图结论的诊断比值不入图。

## 3. 成本传导链（六氟 → 电解液 → 电池）

- `ind.electrolyte.liPF6_cost` = 六氟价 × 单吨电解液六氟用量（三来源等权融合：0.13 中信证券 / 0.12 OFweek / 1GWh 口径反推）。
- `ind.electrolyte.cost_implied` = 锂盐成本贡献 ÷ 锂盐占电解液成本比（民生 50% 与证券时报 40%~50% 等权融合）。
- `ind.electrolyte.gross_spread` = 电解液售价 − 隐含成本；`gross_margin_implied` = 价差 ÷ 售价。
- 2026-09 数据实测：锂盐成本贡献 ≈ 1.40 万元/吨、隐含成本 ≈ 2.87 万元/吨、价差 ≈ 3,624 元/吨、隐含毛利率 P50 ≈ 11%（均值 ≈ 8%、P10 转负）。
- 量级校验参考（不做跨类比较）：天赐材料 2024 年电解液单吨净利 0.25~0.27 万元/吨（华安证券 2024-06），仅用于判断反推成本是否落在行业合理量级，毛利率（%）与单吨净利（元/吨）不是同一口径、不得相减或等同。

## 4. 期间口径纪律

- 2026 六氟供需比 Q3 105% / Q4 93%（中信建投）→ `gap_ratio_q4` = 1 − 供需比 = 7%。
- **禁止跨期比值**（如「Q4 单季缺口 ÷ 全年需求」，曾因此打回）；分子分母期间必须一致，不一致须在 note 声明且不作为结论使用。

## 5. 多源融合约定（本链条首次落地）

同一指标的不同来源**各自建独立数据节点**，一律由下游 `mixture` 等权融合，不在节点内合并、不做人工折中：

- 价格：碳酸锂 3 源、六氟 2 源、三元电解液 2 源、DMC 1 源（生意社 2026-10-01）；
- 参数：六氟单耗 3 源、六氟占电解液成本比 2 源（证券时报 40~50% ＋ 新浪 35%，同期）。
- 分歧过大时引擎自动报 `Method Conflict`（如两源成本占比报 46.1%），如实暴露而不掩盖。

## 6. 已知局限与「不入图」判定

- 电解液 / 电池成本结构部分口径较老（2021、2022 研报），由同源引用/多源融合与 note 声明；
- 宁德时代口径的电解液单项成本占比未披露、未找到；
- **观研天下（2025-11-04）全球供需表未入图**：其正文称 0.7 万吨为 2026Q4 缺口、表格却列为 2026 全年缺口，原文自相矛盾、口径不可对齐（表内 2026 全球需求 38 万吨、有效产能 37.3 万吨、缺口率 1.8%）；
- **中国口径与全球口径并列但不混合**：智研咨询 2026-03-14 的 31.44 万吨为中国需求量、38.52 万吨为中国产量，与中信建投的全球需求量 40.4 万吨不可对照；
- **「0.7 万吨」三处表述疑同源**（中信建投系），不构成独立多来源；
- **价格向下游的传导时滞无权威定量数据**（仅有月度联动≈1 个月、长单≈季度级的机制性描述），未入图——与 TODO「事件时间」同源问题。


## 7. 产品价格 → 公司净利润（价格敞口模板）

核心用例：假设某产品价格较现价变动 X%、持续 N 个月 → 关联公司税后净利润差额与前瞻 PE 变化。粗粒度、敏感度级别。

- **情景旋钮**（`data/sources/ind_price_scenario_knobs_2026.json`，行业级、各公司共用）：`ind.<产品>.price.change`（基线 0 = 不假设变动）、
  `ind.<产品>.price.change_months`（基线 3 = 2026 年剩余月数）。情景文件覆盖旋钮即可，如 `data/scenarios/capchem/电解液涨100%_2个月.json`。
- **模板** `data/templates/price_exposure.json`：每家公司按 `sell`/`buy` 产品列表，每个产品生成
  `raw = 参考价(元/吨) × 变动率 × 月数 × 月均量(万吨/月) × 系数`（万元）→ `pretax = raw × (±1e-4)`（亿元，卖方 +、买方 −）→ `net = pretax × (1−税率)`。
  系数：卖方 = 公司售价对行业价的传导系数；买方 = 每单位产出的原料用量 × 外购比例。
- **加一家公司**：`data/instances/price_exposure.json` 加一条 bind；公司侧加一个汇总节点 `{company}.profit.fy2026.price_scenario = sum(原 2026 利润, 各产品 net)`，
  并把前瞻 PE 实例该公司 2026 的 `profit_ref` 指向它（模板无法生成变长 sum）。
- **新宙邦绑定**：卖电解液（参考价 = H1 单吨收入，系数 β=0.7）；买六氟（单耗 × (1−自供率 50%~70%)）；买 DMC（溶剂系数 0.8）；
  月均量 = H2 电解液出货 ÷ 6；税率 15%。基线下 `price_scenario` 等于原利润结论。
- **口径边界**：情景只计入 FY2026（≤3 个月）；2027/28 PE 不随情景变化，2027 同比以情景 2026 为基数会变化，结论只看 2026 利润差额与 `pe.2026`。
  各产品旋钮相互独立（如六氟涨价是否传到电解液售价，需同时设置电解液 change）。
