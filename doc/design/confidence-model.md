# 置信度模型（Confidence Model）设计细节

## 1. 核心约束：数据节点零依赖

数据节点是原子的：只有 **(原始分布 $p_{raw}$, 置信度 $C$, `source_id`)** 三元组，不引用、不依赖图中任何其它节点（包括自己的历史数据、同行业其它公司数据、图中因果上游节点）。

## 2. 单节点置信度展宽公式

$C\in(0,1]$ 直接、单向地展宽该节点自身的分布，公式只用到这个节点自己的字段：

| 分布 | 展宽公式 |
|------|---------|
| Normal($\mu,\sigma$) | $\sigma_{eff} = \sigma / C$（$\mu$ 不变，故均值=中值=众数 始终等于 $\mu$） |
| SplitNormal($\mu,\sigma_L,\sigma_R$) | 下/上侧各为 50% 半正态，$\sigma_{L,eff}=\sigma_L/C$、$\sigma_{R,eff}=\sigma_R/C$（$\mu$ 不变，中值=众数=$\mu$ 恒定，仅均值随不对称微偏） |
| Uniform(min, max) | 以中点为中心，两端按 $1/C$ 拉伸 |
| Point / Bernoulli | 展宽半宽 $= k\lvert v\rvert\,(1/C - 1)$（$k$ 取 domain 量级的约 1%）。**$C=1$ 时半宽严格为 0 —— audited 等确定披露值退化为精确点，不凭空造噪声**；$C<1$ 才按缺失的置信度展开为绕 $v$ 的小宽度分布 |

> **三角分布（Triangular）已禁用**：非对称三角分布展宽时仅众数不动、均值/中值会向长尾一侧漂移，导致对外展示的代表值与信息来源中心值不一致。所有需要区间/分歧的建模一律改用 Normal（$\mu$=来源中心值，$\sigma$ 取自分歧幅度）；`distributions.sample` 遇 triangular 直接报错。

**Domain 钳制**：每种指标类型注册一个静态物理/常识边界常量（如"价格 ≥ 0""同比增速 ≥ −100%"，随指标类型写入 Schema，不是对其它节点的依赖），展宽后的分布始终按边界截断。$C\to 0$ 时，分布自然收敛到"边界内的均匀分布"（即行业常识宽分布），不需要额外发明一个"先验节点"。

## 3. 多源数据融合（与展宽是两套独立机制）

同一指标存在多个数据节点时（不同 `source_id`，如研报 A、研报 B），**不通过节点间依赖处理**，而是各自独立展宽后，一起接入下游的**融合算子节点**，由算子按各自 $C$ 加权/混合，产出新的输出节点。单一来源与"一论点一锚"规则见 [agents/invariants.md](agents/invariants.md) 铁律 1。

融合语义（供算子实现参考）：

- **Mixture（默认）**：$p(x) = w_A p_A(x) + w_B p_B(x)$。两来源分歧大时保留双峰，如实反映"方法/来源冲突"，应触发 `ALERT: Method Conflict`。
- **乘积/贝叶斯融合**：$p(x)\propto p_A(x)p_B(x)$，适合"两来源本该测量同一真值"的场景，重叠小则给出冲突信号。
- 避免直接加权平均成一个点估计——会制造 README 明确摒弃的"伪精确"。

## 4. 概率传导引擎：蒙特卡洛

- 引擎全程蒙特卡洛：数据节点按展宽后的分布采样，算子逐样本运算。
- 共享上游节点复用同一组样本，相关性自然保留，无需协方差矩阵；非线性算子与多峰/尾部形状不失真。
- 随机种子默认固定，结果可复现。

## 5. 置信度分级规范：类型与数值解耦

为避免不同来源/不同 Agent 自由心证填小数，$C$ 的赋值拆成两层：

- **证据类型 `evidence_type`**：AI 从固定枚举中判定，语义稳定。
- **`type → C` 查表**：程序独立维护、可单独调参。
- 枚举、含义与当前 $C$ 值以 `cgraph/confidence.py` 的 `CONFIDENCE_TABLE` 为准（每类一行注释），本文不重复列出。
  AI 自造的假设一律标 `assumption`；情景覆盖不改变原节点的 `evidence_type`（见 [overlay-scenario.md](overlay-scenario.md)）。

**实时查表，不在节点里烤死 C 数值**：数据节点只存 `evidence_type`，不存 $C$ 数值。每次计算（展宽/融合）时用当前的查表结果取 $C$。改表（比如回测发现 `analyst_estimate` 该从 0.6 调到 0.5）后，重新跑一遍图计算即可，**所有节点的结果自动跟着变准**，不需要改任何一条已入图数据。暂不引入版本号/生效时间等审计机制——按敏捷/第一性原理，这类复杂度等真的需要追溯"某次结果用的哪版表"时再加。

## 6. 对外展示的代表值：用中位数(P50) + P10–P90 区间，不展示均值

展示一律取中位数 **P50**：中位数对偏态更稳健、更贴近分布众数(mode)，而均值会被长尾拖偏。
因为三角分布已禁用、数据节点统一用 **Normal / SplitNormal**（中值=众数=$\mu$，且展宽时 $\mu$ 不变），
单个数据节点的 P50 稳定等于其信息来源中心值（如券商一致预期均值），不因置信度展宽而漂移（SplitNormal 用于下宽上窄等不对称分歧，仍保证中值=$\mu$）。
下游经非线性算子/融合后的节点仍可能呈偏态，此时 P50 仍是比均值更稳健的展示口径。因此
 CLI（`render.py`）与 Web 卡片（`web/index.html`）大字号 headline 一律显示 **P50**，配 P10–P90 区间；
**均值不展示、引擎也不输出**（比值类节点的均值会被极少数分母近 0 的样本拖到无意义量级）。跨节点求和/期望值等
需要可加性的计算场合用样本本身，不受此展示
约定影响（引擎内部全程 Monte Carlo 样本传导，展示口径不影响计算口径）。

**PE 类比值的分位口径**（算子节点 `quantile_order: "inverse"`，模板 `forward_pe_multiyear` 已对全部前瞻 PE 启用）：
利润跨 0 时 PE 不连续、数值大小与估值贵贱失序，故按 $1/x$（盈利收益率）排序取分位——正 PE 由低到高，
亏损（PE≤0）视为最贵一端；落入亏损区的分位显示 **NM**，另输出**亏损概率**（PE≤0 样本占比，为 0 时不显示）。
PE 全为正时与普通分位完全一致；仅影响展示统计，不改样本。
