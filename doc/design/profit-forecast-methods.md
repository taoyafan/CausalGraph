# 从财报外推未来利润（profit-forecast-methods）

> 对应 [README §2.7](../../README.md#27-参考建模范式从财报外推未来利润)。一个可复用的建模范式。

**用已披露的半年报（audited）作为硬锚，从财报里的前瞻信号推断下半年利润**，而非拍脑袋给全年数。

## 1. 结构统一为「实际 + 外推」

- `全年 = H1 实际(audited) + H2 外推`；主观性只落在少数 assumption 系数上，其余全是图内纯数学算子（数据零计算）。

## 2. 从财报的三类前瞻信号锚定 H2

按行业与披露口径任选其一或并用：

- **存货法（备货侧）**：`历史比率 = 存货 ÷ 对应期营业成本` 校准后，用期末存货反推 H2 营业成本 → 营收 → 利润；适合备货领先出货的制造业。
- **产能法（供给侧）**：`历史周转率 = 营收 ÷ 期初固定资产` 校准后，用期末固定资产 × 前瞻周转率推 H2 营收 → 利润；适合产能前置扩张的重资产企业。
- **在手订单法（需求侧）**：以合同负债/在手订单等锁定的收入为基推 H2；适合订单可见度高的业务。

## 3. 多方法独立并行、再融合暴露分歧

- 每种方法各建独立路径（各含自己的审计锚 + assumption），用 `mixture` 等权融合；视角分歧过大时引擎自动触发 **Method Conflict** 告警，而不是掩盖成一个单值。
- **无法机械外推时不硬凑**：若关键增量是台阶式事件（如新平台放量），可直接采用**券商一致预期**（多家 `analyst_estimate` 等权融合）作为一条独立路径，与自下而上路径并列。
- **佐证只陈述不入图**：应付账款、经营现金流、在建工程等旁证可写进 `note` 印证方向，但不得作为分布参数的推导链。

## 4. 实例

```
python -m cgraph.cli focus shenghong.profit.fy2026   # 胜宏科技：存货法 × 产能法 × 券商法三路融合
python -m cgraph.cli focus litong.profit.fy2026      # 江苏利通电子
```

直接看建模输出：分位区间、假设清单、Method Conflict 告警。
