# 投资沙盘移动端显示设计：公式钻取模型

> 状态：已决策（显示方案）。覆盖式演绎的显示为未来扩展，见 overlay-scenario.md §6。

## 1. 核心取舍

手机端**不做节点画布图**（缩放拖拽、force 网状图），以**公式为推导的呈现主体**，
钻取路径即页面栈。卡片 + 逐层点击细分。

理由：图会持续增长，画布在小屏上每次读数要两三步操作；而推导本质是
"每个结果 = 哪个公式 + 哪些输入"，公式卡天然竖排、天然分层。

## 2. 页面结构

### 2.1 首屏：结论卡片列表

每个关注目标一张卡：指标名、P50 大字、P10–P90 区间条、
一行风险摘要（假设节点数 / 最低置信度 / 告警）。零操作直达。

### 2.2 公式钻取页（主体）

每个**算子节点**一张"公式卡"，自上而下三段：

1. **公式头**：该算子的公式形态（模板），如
   `全年毛利 = H1收入 × (2 + g3) × H1毛利率 × 调整系数`
2. **结果**：P10 / P50 / P90 + 区间条；告警节点红色标记
3. **输入插槽列表**：每个上游节点一行
   - 上游是算子节点 → 显示名字 + 结果摘要，点击进入下一张公式卡
   - 上游是叶节点（数据）→ 显示名字 + 值 + 证据类型色点（绿 audited /
     黄 assumption / 其余蓝），点击进数据详情

共享节点（如同一个调整系数出现在 4 个分部下）只实体展开一次，
其余位置显示"同上"引用，点击跳转实体。

### 2.3 叶节点详情：底部半屏抽屉（非全屏页）

- audited 数据：来源、原文引用、数据时点、来源链接
- 假设节点：分布三值 + 假设理由（quote）

用抽屉不加深页面栈——钻到假设理由看完即滑掉，保持"扫一眼继续想"的节奏。

### 2.4 面包屑

页面栈即推导路径（归母净利润 → … → 某季节性假设），无需额外设计。

## 3. 公式模板库

- 每个算子注册一个**公式字符串模板**，与 operators.py 的"定义即代码"一一对应；
- 与 CLI level 3（`cgraph/render.py` 的 `_formula_expr`）共用模板定义：
  模板写一次，CLI 渲染文本、端上渲染卡片；
- 端上需要"公式头 + 插槽列表"两段式结构，CLI 的一次性内联展开不够用，
  需给 webexport 加**按节点的钻取 API**（数据全在 engine，仅换序列化方式）。

## 4. 未来扩展（本文不展开）

原值/临时值并排区间条，骨架不变。见 overlay-scenario.md。
