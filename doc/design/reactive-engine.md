# 层级解包与响应式风控引擎（reactive-engine）

> 对应 [README §2.4](../../README.md#24-层级解包与响应式引擎)。本文只记最终结论。
> 现状：引擎仍为「每次命令全量重扫重算」，本节为待实现目标（见文末）。

## 1. 全局图缓存与增量计算

- 全局图与各节点样本**持久化缓存**，与"加节点"解耦：新增/变更数据源时只**扫描增量节点并入全局图**、只重算受影响的下游子图，查询直接**读缓存**，避免每次全量重建重算。

## 2. Baseline + Delta 层级结构

- 采用 `新总值 = 基线 + Delta` 算子叠加微观事件，解决宏微观层级打架问题。

## 3. 下游脏标记与变化阻断

- 更新发生时沿 Downstream 拓扑路径做 **Dirty Marking**；若算子输出无明显变化，触发 **Short-circuiting（变化阻断）** 终止后续计算。

## 4. 自动化风控链路

- 下游概率方差剧烈膨胀或数值离群 → 阻断传导 → AI 自审 → 上报管理员待办 → 生成定向 AI 补全 Task。

## 5. 实现现状

- 当前 `cgraph` 每次命令都从 `data/` 全量加载并全量求值，无缓存层；上述四项均为设计目标，尚未实现。
