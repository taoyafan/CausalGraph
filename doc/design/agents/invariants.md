# 全体 Agent 必守的铁律（Shared Invariants）

所有角色，无论 harness，都必须遵守以下不可协商的约束（与 [README](../../../README.md) 设计哲学、
[AGENTS.md](../../../AGENTS.md) 数据诚实性原则一致）。本文件是唯一事实源，各角色提示词
（[scout.md](scout.md) / [reviewer.md](reviewer.md) / [operator-author.md](operator-author.md)）
开头引用本文件，不复制正文：

1. **数据/算子严格分离**：数据节点**零计算**——只含 (分布, `evidence_type`, `quote`, 出处)，
   不引用任何其它节点、不内联任何换算公式。一切计算都由**算子节点（代码）**完成。
   - **严格单一来源（铁律）**：一个节点只能对应一个数据源/一条证据（单一 `Source_ID`），
     **严格禁止单个节点引用/合并多个数据源**，数据节点与假设节点一视同仁。
     数据节点：同一指标的多源（不同 `Source_ID`，如研报 A/B）必须各建独立节点，
     由下游**融合算子节点**（mixture）加权/混合产出新节点；禁止把多个来源的数字合并、
     平均、加权后直接塞进一个节点。
     假设节点：**一论点一锚**——quote 可内嵌多条**同向支撑同一论点**的证据（事实 + 来源 URL + 日期），
     只要它们把众数往同一方向推；真正必须拆开的是**反向驱动/多方法交叉验证一个值**，各建独立假设锚、
     由下游算子（融合/加权汇总）合成，**不得在一个 quote 里把分歧权衡/交叉验证成一个单值**。判据＝换
     驱动检验（见铁律 4）：单独改某条证据、本锚取值是否应独立朝某方向变而当前分布表达不了？是→拆；否→
     一个锚即可。不得按字面数证据条数打回。
   - **值的来源也必须零计算**：节点存的值只能是 ① 来源**直接披露**的数字，或 ② **直接拍定的主观先验**（assumption）；
     **不得等于“对其它数字做算术”的结果**。若某值是用公式/算术从别的量算出来的（哪怕精确成立、哪怕标了
     assumption），必须把该算术做成**图内算子**由其产出。典型反例：把 `H1归母 ÷ H1毛利 = 0.551` 手算后烘焙进 assumption 节点。
   - **唯一允许的图外操作**：单个来源数字的**无损转写**（单位换算 元→亿、百分数 15.32%→0.1532），因它不组合其它量、不引入判断。
   - **判据**：若节点 quote 出现『本节点值 = a 运算 b』且该值并非独立披露，即为“图外计算烘焙”，违规。
2. **算子是受控代码，不是即兴公式**：需要新算子时，必须作为**提交进代码库、可复现、可评审**的
   具名函数入库（`cgraph/operators.py`），绝不在数据节点 quote 或运行时内联生成公式。
3. **禁止冒充，允许透明的非 audited**：可以有外推/假设/第三方估计节点，但 `evidence_type`
   必须如实标注；AI 自造的假设显式标 `assumption` 并请人确认，不替协作者拍板。
4. **100% 可溯源**：每个数据节点必须带 `source_url` + `quote` + `as_of`（+ 源级 `retrieved_at`/`publisher`，
   `source_url`/`as_of` 可继承自源级文件头）；取不到就如实标缺口，绝不编造来源或叙事。
   - **假设节点自足承载证据（铁律 1"零依赖"的推论）**：假设节点本身就是引用数据源的节点——
     其 `quote` 直接内嵌证据（事实 + 来源 URL + 日期），仿 audited 节点带出处的写法。
     **禁止为"证据"单独建一层数据节点**（数据节点不得引用其它数据节点）：那会产生孤儿节点
     （数值不参与计算）与三层冗余（假设→证据→原始来源）。定性表态（无法数值化）同样内嵌 quote。
   - **一论点一锚（禁的是交叉验证/权衡出单值，不是引用条数）**：拆分单位是"一个方向性论点/情景"，
     不是"一条事实"。一个假设锚的 `quote` **可以列多条同向支撑同一论点的证据**（有的定众数、有的托
     下界/封上界），只要它们把众数往同一方向推，就归一个锚——这不算违规。真正必须拆开的是**交叉
     验证/反向驱动**：① 反向驱动混锚（一条撑高一条压低、脑内权衡出中间数）、② 多方法交叉验证一个值
     （产能法算 X、券商法算 Y 取折中 Z）——这两类各建独立假设锚、由下游 `mixture`/`sum`/加权算子融合，
     让图诚实暴露分歧。**判据＝换驱动检验**：单独改 quote 里某条证据，本锚取值是否应当独立地朝某方向
     变、而当前这一个分布表达不了？是→拆；否→一个锚即可。**不得按字面数 quote 里的证据条数打回。**
     注意：拆的是"多个假设节点"（各自有值、参与计算），不是为证据另建数据节点层（那是禁止的孤儿层）。
5. **遇阻不放弃**：缺算子/缺数据/有冲突不是删节点的理由，而是走"问题→解决方案手册"（见
   [agent-teams.md §4](../agent-teams.md)）。
6. **全局唯一 id 命名空间**：数据与算子共用一套全局唯一 id；图必须是 DAG，禁止成环。
