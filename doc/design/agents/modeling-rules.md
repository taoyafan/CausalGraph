# 建模规范（Modeling Rules）

> 建模规范的唯一事实源。**主 Agent 设计建模方案前必读、Model Reviewer 按同一份逐条审**
> （生产者与审核者共用同一份文字，否则制衡失效）。数据层铁律见 [invariants.md](invariants.md)，本文件只管
> "怎么把数据/假设/算子连成方案"。新增建模教训只改本文件一处。

① **口径与量纲一致**：算子每个 input 的口径（时点/地域/统计范围/单位）是否可比？分子分母、被加项之间
   口径混用一律不允许（如中国口径 ÷ 全球口径、半年量 × 全年价、元/吨 与 元/GWh 直接相乘未换算）。须在
   算子 note 声明口径，口径不可对齐的量禁止进同一算子。

② **禁止跨期比值**：算子若做比值/差值，分子分母的报告期必须一致；跨期相除（如"Q4 单季缺口 ÷ 全年需求"）
   不允许。不一致须拆期或在 note 声明且不作结论。

③ **禁止时变内容跨期融合（铁律 8）**：凡用 `mixture` 融合的多源，逐个核对 `as_of` 是否同期。
   价格/成本占比/市场份额/供需比等**时变量**不得跨 vintage 等权融合：只用最新同期值、旧值降为
   quote 参考不入计算、或显式建时点节点。只有**时间稳定的技术系数**（化学配比、单位物料用量等物理约束量）
   才允许跨 vintage 融合，且须在 note 说明其时间稳定性。**旧 vintage 点源坍塌 mixture 中位数**（点质量把
   P50 拉到旧支路）时，要么去掉旧点源、要么明确"并列展示各支路、不取 P50 当结论"。

④ **mixture 输入须是同一量、同一覆盖范围的完整估计**：`mixture` 的每个输入都必须独立回答**同一个问题**
   （同一个量、同一统计范围），只是方法/信源不同。**只覆盖部分成分的路径**（如只算六氟成本对电解液价格的
   影响，暗含"溶剂/添加剂不变"）不得直接与整体估计 mixture——须先用 `sum`/`product` 补齐其余成分（缺数据用
   显式 assumption 锚），成为完整估计后再融合。**判据**：该输入要成立，是否依赖一条未入图的"其余不变"隐含
   假设？是 → 补齐。原位替换 mixture 的某个输入时，须核对新输入与被替换者回答的是否仍是同一个问题。

⑤ **先搜数据、后定算子**：方案里每个数据/假设节点的取值须有具体 Scout 事实支撑（来源+日期）。凭空拍的
   分布参数、没有数据侦察就预设的算子（拿锤找钉）不允许，先补数据侦察。

⑥ **数据/算子/假设三分离**：计算都归算子、数据节点零计算、主观判断落成原子 assumption。不得把算术烘焙进
   数据/假设节点的取值（值 = 对其它量做运算的结果），须拆成 数据节点 + 图内算子。

⑦ **一论点一锚**：假设锚是"对单一量、朝单一方向的直接判断"。反向驱动/多方法交叉验证不得权衡成一个单值，
   须各建独立锚 + 下游融合算子，让图暴露分歧（用换驱动检验判定，见 [AGENTS.md](../../../AGENTS.md)
   "假设锚颗粒度约定"，不按证据条数判定）。

⑧ **因果方向与 DAG**：算子的 inputs→output 须符合因果/构成方向（上游材料价 → 下游成本，而非反向）；接入
   新边不得成环。成环或因果反向须重审方向或引入 Baseline+Delta 分层。

⑨ **分布类型与置信度诚实**：分布类型匹配证据形态（点估计用 point、硬边界区间用 uniform、有中心的区间/分歧用
   normal/split_normal，triangular 已禁用；软判断给足宽度，注意引擎按 σ/C 展宽、勿双重放大）；evidence_type 如实（实测 market_observed、券商 analyst_estimate、
   AI 拍定 assumption）。软性叙事不得给 2~3 位小数的伪精确。

⑩ **缺口诚实**：缺同期/权威数据时如实降级（宽分布 + 低置信度 + 请人确认），不硬凑、不用旧值冒充当期；
   不删节点/退化功能回避问题，走 [agent-teams.md](../agent-teams.md) §4"问题→解决方案手册"。

⑪ **颗粒度：精度服务于结论，够用即止**：价格→利润类推演默认用"价格 × 敏口"的敏感度模型（[industry-lithium.md §7](../industry-lithium.md)）。
   一项细化（口径拆分、逐月序列、基差锚等）若不改变"价格变动 → 净利润变动"的结论（落在已有区间内）就不做；
   不参与任何利润/视图结论的诊断比值不入图（核对结论写进 note 一句话）。节点越少，维护与审核成本越低。
