# 锂电产业链图 v1（碳酸锂—六氟—电解液—电池）

> 状态：**讨论中（尚未决策）**。对应 README 需求 6/7 的第一条落地链。
> scout 已交付 86 条环节级原子事实（未落盘），本文只是建模方案，不是最终设计。

## 1. 目标

以宁德时代（catl）与新宙邦（capchem）共同所在的锂电产业链为第一条链，建**环节级**骨架，
把两家公司挂到对应环节上，为后续「事件 → 受影响公司盈利」打底。

## 2. 环节骨架

碳酸锂 → 六氟磷酸锂 → 电解液（溶剂 / 添加剂）→ 电池（宁德时代）
